# English Garden

一個繁體中文介面的遊戲化英文練習網站。

## 遊戲功能

- B1、B2 進階字彙闖關與句子填空：每題標示 CEFR 級別，答對獲得 XP，連續答對有加成。
- 聽力探索：使用瀏覽器內建的語音合成功能播放單字。
- 每日三項任務、等級、連續學習紀錄與徽章收藏。
- 學習進度存在各訪客自己的瀏覽器 `localStorage`。
- CEFR 級別參考 Oxford 3000 by CEFR level 詞表；不同詞典與語境可能有差異。

## 隱私

網站沒有登入、個資欄位、分析追蹤或外部生成式 AI API。學習紀錄留在使用者裝置上。網站本身不包含後台服務；公開代管服務可能會依其政策記錄一般連線資訊。字型使用裝置上的系統字型，不會連到 Google Fonts。

## 本機預覽

開啟 `index.html` 即可使用；語音播放需瀏覽器支援 `speechSynthesis`。
